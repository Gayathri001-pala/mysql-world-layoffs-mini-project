
# 🧹 MySQL Mini Project: World Layoffs Data Cleaning

This **mini project** focuses on cleaning and preparing a **World Layoffs dataset** using **MySQL**.  
The goal was to practice real-world data cleaning techniques and prepare messy data for accurate analysis.

## ✅ Key Tasks Performed
- Removed duplicate rows using `ROW_NUMBER()`
- Handled missing and inconsistent values
- Standardized company, industry, and location names
- Fixed date formats using `STR_TO_DATE()`
- Trimmed spaces and replaced empty fields with NULLs
- Deleted incomplete records

## 📁 Files Included
- `layoffs_data_cleaning.sql` → full SQL cleaning script  
- `world_layoffs_sample.csv` → dataset 

## 📚 Tools Used
- MySQL  
- SQL Workbench / MySQL Shell  
- SQL
## 🎯 Key Learnings
- Importance of clean and consistent data  
- Using window functions for deduplication  
- Applying SQL transformations for real-world data cleaning
